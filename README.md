# T-Mod
a MultiplayerPiano mod that aims to improve performance and add more functionality

wanted to make a redo of HyperMod v2 and have it be better & stronger
so, I made T-Mod

## features
- Many, many, many optimization settings
- Sent message history scrolling
- 128-key support
- Built-in MIDI player *(supports `.zip` files)*
- Client chat commands

## Settings Menu
There is no settings menu yet—settings, at the moment, are modified within the code via `src/modules/settings/tmod`.

## Building
To build T-Mod:
1. install [Bun](https://bun.com)
2. run `bun install`
3. run `bun build:min`

Pretty easy, huh?
