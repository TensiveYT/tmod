# T-Mod
a MultiplayerPiano mod that aims to improve performance

wanted to make a redo of HyperMod v2 and have it be better & stronger
so, I made T-Mod

## features
- many many many optimization settings
- sent message history scrolling
- 128-key support
- built-in MIDI player
- client chat commands

## building
to build it:
1. install [Bun](https://bun.com)
2. run `bun install`
3. run `bun build:min`

pretty easy
